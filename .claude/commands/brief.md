## ⛔ ЗАЛІЗНІ ЗАБОРОНИ (це брифінг, НЕ виконання)

- ЖОДНОГО Edit/Write у файли репо. ЖОДНОГО git commit / push / PR / merge.

- Дозволено: Read/Grep/Bash-читання, `npm install` + запуск перевірок (вони нічого не міняють), GitHub MCP читання.
- Єдиний вихід — звіт у чат за форматом нижче. Файлів-звітів НЕ писати (рішення Романа 04.07).

## Крок 1 — Мінімальний контекст (свіжа сесія знає мало)

Прочитати РІВНО це (не повний /start — брифінг має бути швидким):
1. `_ai-tools/SESSION_STATE.md` — шапка «Оновлено» + поточний блок сесії + секція «⚠️ ДЛЯ НОВОГО ЧАТУ» (особливо «НАСТУПНИЙ КРОК»).
2. `NEVERMIND_BUGS.md` — секції 🔴 і 🟡 (тільки ВІДКРИТІ рядки, закриті пропускати).
3. `ROADMAP.md` — тільки секція «🚀 Active» (перші ~60 рядків).
4. `_ai-tools/BYYOU_PLAN.md` — статус: якщо `active`/`paused` — є НЕЗАВЕРШЕНИЙ потік, це пріоритет №1 звіту («продовжити /byyou»), чернетку нового блоку тоді НЕ складати.

## Крок 2 — «Чи все чисто» (перевірки, всі read-only)

1. **CI через GitHub MCP** (`actions_list`, останній прогін кожного): `e2e.yml` · `auto-merge.yml` · `canary.yml` · `gitleaks.yml` · `ai-smoke.yml` (може бути skip без ключа — це не червоне). Червоне → `get_job_logs` (failed_only) → 1 рядок «який тест/чому».
2. **Відкриті Issues** (GitHub MCP list_issues, state=open): мітка `canary` = зламаний прод, пріоритет №1; мітки `security`/`claude-sec` = у секцію пріоритетів як «розібрати/тріажнути» (не дати гнити — знахідка першого смоуку 04.07: 2 Issues висіли з травня).
3. **Локальні сторожі:** `npm install` (~1 хв) → `for f in scripts/check-*.js; do node $f; done` → `npm run lint` → `npx playwright test --list` (тільки парс). Будь-яке червоне — у звіт з назвою сторожа.
4. **Гігієна:** `grep -c "^<details>" _ai-tools/SESSION_STATE.md` (>1 → «потрібна ротація») · `git fetch origin main && git log --oneline -1 origin/main` (свіжість main).

## Крок 3 — Беклог за пріоритетом (джерела У ЦЬОМУ порядку)

1. 🔴 критичні баги з NEVERMIND_BUGS.md (відкриті).
2. Відкриті canary-Issues (прод зламаний).
3. Незавершений /byyou (статус active/paused у BYYOU_PLAN.md).
4. `SESSION_STATE` → «🎯 НАСТУПНИЙ КРОК» + «📋 ЧЕРГА».
