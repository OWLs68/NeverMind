# /qa-explore — Хмарний смоук: Claude сам кликає застосунок у браузері

> **Що це:** експлораторний прохід по ЗІБРАНОМУ застосунку прямо у хмарній сесії Claude —
> без CI, без iPhone. Клод збирає bundle, піднімає локальний сервер, відкриває Chromium,
> проходить зачеплені екрани, збирає JS-падіння і скріншоти. Народжено з дослідження
> gstack `/qa` (26yz5s 03.07, ADR-004), але БЕЗ їхнього двигуна — наш Playwright достатній.
>
> **Коли:** (а) обовʼязковий крок Фази 3 `/byyou` перед реліз-нотатками; (б) на запит
> Романа «подивись сам / прокликай / перевір екрани»; (в) після великого UI-батчу.
>
> **Чого НЕ замінює:** живий iPhone. Гумовий скрол, поведінка PWA з домашнього екрану,
> справжні свайпи — тільки руки Романа. Мета скіла — щоб у його чек-листі лишались
> ТІЛЬКИ ці iOS-специфічні пункти.

---

## Крок 0 — Середовище (раз на сесію)

Мережеве обмеження хмарної сесії: зовнішні сайти Chromium НЕ бачить (проксі ріже),
але **localhost — бачить**. Тому смоук завжди по локальній збірці, не по проду.

```bash
# Місток версій браузера (у сесії стоїть chromium іншої збірки ніж хоче наш Playwright):
SP=<scratchpad-сесії>   # директорія скретчпаду
mkdir -p $SP/pw-browsers/chromium_headless_shell-<N>/chrome-headless-shell-linux64
ln -sfn /opt/pw-browsers/chromium_headless_shell-*/chrome-linux/headless_shell \
  $SP/pw-browsers/chromium_headless_shell-<N>/chrome-headless-shell-linux64/chrome-headless-shell
touch $SP/pw-browsers/chromium_headless_shell-<N>/INSTALLATION_COMPLETE
# <N> = версія яку просить помилка запуску playwright (напр. 1223). Обидва симлінки
# (chromium-<N> теж) — див. як робив v3pexs при E2E #39 і 26yz5s при канарейці.
```

## Крок 1 — Збірка + сервер

```bash
npm install            # якщо node_modules ще нема
node build.js          # свіжий bundle.js
python3 -m http.server 4173 &   # локальний сервер (run_in_background)
```

## Крок 2 — Прохід (ad-hoc driver-скрипт у скретчпаді, НЕ у репо)

Написати одноразовий node-скрипт на playwright API (бібліотека вже у node_modules):
- `addInitScript`: `nm_onboarding_done=1` + `__NM_TEST_SEED__=true` (глушить тури).
- За потреби — сіяти тестові дані (як `seedState` у tests/e2e/helpers.js).
- OpenAI: глушити route.abort (безкоштовно) АБО лишити живим якщо є ключ і мета — AI.
- Пройти ЗАЧЕПЛЕНІ у сесії екрани: `window.switchTab('<tab>')` → скріншот → перевірити
  видимість ключових елементів → зібрати `pageerror` і `console.error`.
- Скріншоти у скретчпад → показати Роману (SendUserFile) лише проблемні або підсумкові.

## Крок 3 — Вердикт

1. **0 падінь + екрани як очікується** → у реліз-нотатках «ЩО ПЕРЕВІРИТИ НА IPHONE»
   лишити ТІЛЬКИ iOS-специфічне (свайпи/гума/PWA) — решту позначити «✅ хмарний смоук».
2. **Падіння/зламаний екран** → це знахідка ДО деплою: корінь → фікс → повторити прохід.
3. У пульсі /byyou — один рядок: «🔍 хмарний смоук: N екранів, 0 падінь, скріни ⬆️».
