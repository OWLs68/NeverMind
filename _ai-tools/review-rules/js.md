# Чекліст JS (шрами з lessons.md — перевіряти КОЖЕН пункт проти diff)

- **\b-кирилиця:** будь-який regex з `\b` поруч із текстом що може бути кирилицею — ПРАПОР (у JS `\b` не матчить кирилицю; 3 мертві вартові жили місяцями). Межа для кирилиці: `(?<![а-яіїєґ])…(?![а-яіїєґ])` або без `\b` взагалі.
- **Re-export ≠ локальне імʼя:** `export { x } from './y'` НЕ робить `x` доступним у цьому ж файлі → виклик = тихий краш (B-201). Треба import + export окремо.
- **Переніс функції між файлами:** перенесена функція мусить тягнути СВОЇ константи/змінні модуля (E2E #39 — вкладка мовчки мертва).
- **ID тільки generateUUID()** — ніяких `Date.now()+Math.random()` (колізії, Supabase).
- **Запис у сховище тільки через канонічні сеттери/фабрики** (Ворота 1) — прямий setItem лише у boot-міграціях.
- **Static import, не dynamic** — `await import()` валить check-imports і CI.
- **Нове UI-текст → `t('key','fallback')`** (whitelist: src/ai/, src/owl/, console, коментарі).
