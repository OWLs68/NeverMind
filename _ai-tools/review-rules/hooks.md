# Чекліст хуків/сторожів (.claude/hooks + scripts/check-*)

- **Мертвий guard з народження:** чи ДОСЯЖНА умова взагалі? (клас \b-кирилиця: вартовий «момент» ніколи не матчив). Перевір руками один позитивний і один негативний кейс.
- **Fail-open за замовчуванням:** помилка САМОГО хука не має блокувати роботу (exit 0 у catch). exit 2 — тільки свідомий блок.
- **Не зламати існуючі пороги:** context-guard 75/exit2, push-замок — регресія тут = випадковий деплой або втрачена робота.
- **Новий сторож = контракт-тест** у scripts/check-*.js + реєстрація у pre-push і e2e.yml (обидва!).
- **Секрети у логах:** хук пише у файл/stderr → маскувати ключі/PAT.
