## Реліз-нотатки (перед «деплой»)

**ЩО ЗМІНИЛОСЬ:**
- Фінанси «Останні операції»: транзакції згруповані заголовками по даті (Сьогодні / Вчора / дата) — список і модалка «Всі операції». Дату прибрано збоку рядка (тепер у заголовку дня).
- Inbox: момент тепер підтверджується «📝 у Моменти (вкладка Вечір)» замість хибного «📅 Подію додано» — юзер знає де шукати.

**ЩО МОЖЕ ЗЛАМАТИСЬ (міні pre-mortem):**
- Фінанси: групування — суто рендер, дані не чіпались. Якщо у транзакції кривий `ts` → потрапить під свій день (edge, безпечно).
- Inbox момент: змінив лише текст підтвердження, логіку збереження не чіпав.

**ЩО ПЕРЕВІРИТИ НА IPHONE (≤5):**
- [ ] Фінанси: «Останні операції» — є заголовки «Сьогодні» / дата, транзакції під своїм днем.
- [ ] Модалка «Всі операції» — так само згрупована.

## Реліз-нотатки #3 (bare-noun чіпи) — перед «деплой»

**ЩО ЗМІНИЛОСЬ:**
- Одне слово (напр. «Хімчистка») тепер ЗАВЖДИ дає **справжні клікабельні чіпи** «куди записати? [Створити проект / У щоденник / Як момент / Не зберігати]» — навіть коли AI відповів текстом без інструмента (раніше — текстова імітація «- [...]»).
- Працює у 7 чатах (inbox/finance/me/evening/projects/notes/habits; health — ні, EU AI Act).
- **Стоп-лист привітань** гасить false-positive: «Так/Ні/Дякую/Окей/Привіт…» (~30-40% коротких реплік) → БЕЗ чіпів.

**ЩО МОЖЕ ЗЛАМАТИСЬ (міні pre-mortem):**
- Однослівне слово не зі стоп-листа («Дощ», «Кафе») → дасть чіпи. Прийнятно (один мозок, юзер може записати). Стоп-лист розширюваний.
- tool-path поведінка не змінилась (обгорнув suspicious-перевірку в `if tool>0`) — підтверджено check-chat-uniformity.
- Автотест нездійсненний у node (browser-імпорти) → покрито емуляцією логіки 8/8 + смоук. Борг: винести чисту логіку як tool-filter.

**ЩО ПЕРЕВІРИТИ НА IPHONE (≤5):**
- [ ] Inbox: одне слово «Хімчистка» → клікабельні чіпи (тапаються!), не текст.
- [ ] Те саме у Фінанс-чаті (де ти бачив баг) + Нотатки/Задачі.
- [ ] «Дякую» / «Окей» / «Так» → звичайна відповідь, БЕЗ чіпів «куди записати».
- [ ] Тап по чіпу («У щоденник») → реально зберігає.
- [ ] Звичайна фраза «купив каву 50» → працює як раніше (не перехоплено).

**ВІДКЛАДЕНО:** #3 bare-noun чіпи — ✅ ЗРОБЛЕНО цим заходом (Council відпрацював).
